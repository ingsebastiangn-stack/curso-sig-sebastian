# Curso SIG y servicios web

Repositorio de ejercicios del curso de Sistemas de Información Geográfica y servicios web.

## Datos

Incluye el archivo GeoJSON de hospitales del departamento de Boyacá.

## Cómo se ejecuta

Los ejercicios se ejecutan siguiendo las instrucciones de cada práctica.

## De dónde salen los datos

Paquete de Boyacá descargado con `scripts/descargar_boyaca.py` (IDE Boyacá y DANE).
